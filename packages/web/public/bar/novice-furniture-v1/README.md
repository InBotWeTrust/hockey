# Novice furniture variants

Created with built-in image_gen, precise-object-edit, transparent_background=true.
Original assets are unchanged. The source canvas sizes and scene rectangles are retained.
The battleship and checker table outputs were mechanically resized by one pixel to match the source dimensions (1315x1196 and 1293x1216). Chairs are 1024x1536; cards table is 1448x1086.

Prompt set: remove only the seated person and reconstruct their empty leather chair, or remove only the game/board/cards and reconstruct continuous wood. Preserve original furniture outline, position, scale, perspective, colors, lighting, texture and transparent canvas; never crop or recenter. Each asset was edited separately using its corresponding original as the edit target.

Sources: map-v30/timofey-neutral-v1.webp, map-v36/arsenich-neutral-v1.webp, map-v30/maria-neutral-v1.webp, map-v30/battleship-table-v1.webp, map-v30/checkers-table-v1.webp, map-v36/cards-table-v1.webp.

Generated surface texture and inferred occluded furniture are not pixel-identical to the original. The amateur layers retain the originals. Empty furniture is decorative and has no hit targets. Grigory's available card table retains its cards.
