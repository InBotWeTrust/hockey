# «Меткость» V4: проверка эталонных 87 ситуаций

Источник — обезличенный численный повтор первого периода экспресс-дуэли из пользовательского разбора. Production использовался только для чтения; идентификаторы людей и матча, а также исходный session seed в fixture не сохранены. Ручные названия коллеги — сравнение, не автоматическая истина.

## Фактические исходы и шанс

- 87/87 результатов `goal`/`save`/`miss` совпали с записью; голов 70.
- Закрыты №29, 42, 61, 74, 81 — те же пять, что в ручном разборе.
- Релевантных незабитых ситуаций 12; №4, 9, 48, 76, 85 имеют окно <25 мс и выделены как `too_short`, а не как обычная человеческая ошибка. Остальные семь — `human_error`.
- №48 становится релевантным при поиске ±600 мс: ближайшее окно начинается позже 250 мс. V3 остаётся на прежнем ±250 мс.

## Почему 46 ручных названий отличаются от строгих V4

Ниже перечислены **все** номера расхождений. V4 использует ровно одну награду и согласованный приоритет. Для незабитого броска категория относится к ближайшему голевому моменту, а не к неудачной позиции шайбы. Это сравнение не меняет фактический исход и не подгоняет пороги по номеру броска.
