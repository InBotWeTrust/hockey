# Ревизия механики заданий

Рабочая таблица для согласования типов прогресса и порогов. Можно свободно редактировать столбцы **Тип** и **Уровни / условие**, а свои решения писать в крайнем правом столбце **Мой комментарий — писать здесь**. Столбец **Комментарий Codex** содержит мои замечания и остаётся без изменений.

Если строка в **Мой комментарий** остаётся пустой и значения задания не изменены, это означает, что задание менять не нужно. Перед реализацией Codex всё равно сравнит каждую строку с актуальным каталогом и проверит механику на возможные ошибки.

Типы прогресса:

- **Накопительная** — общий карьерный показатель сохраняется между уровнями.
- **Со сбросом** — внутренняя серия обнуляется при поражении или нарушении условия, но карточка сохраняет лучший результат текущего уровня; после получения награды следующий уровень начинается с нуля.
- **Лучшая попытка** — в прогрессе хранится лучший подходящий результат, полученный после открытия текущего уровня. После получения награды следующий уровень открывается с нулевым прогрессом.
- **Новая попытка 0/1** — составное условие выполняется целиком в новой игре, тренировке, дуэли, периоде или серии; прогресс показывает `0/1`, а не внутренний числовой порог условия.
- **Разовая** — уровней нет, задание выполняется один раз.

Правило прогресс-бара для многоуровневых заданий:

- пока уровень не выполнен, показывается лучший результат текущего уровня;
- более слабая следующая попытка не уменьшает уже показанный результат;
- выполненный, но ещё не полученный уровень показывает заполненный прогресс-бар;
- после нажатия «Забрать награду» следующий уровень открывается с `0` и не получает результаты, сделанные до момента открытия;
- для процентов сохраняется лучший процент, для шайб, серий и разницы — лучшее количество;
- у составных условий, где игрок должен один раз выполнить всё условие целиком, шкала всегда `0/1`.

Статусы:

- **Активно** — показывается игрокам и входит в текущий счётчик.
- **Будущее** — показывается как будущее задание.
- **Скрыто** — не показывается игрокам.

## Решения для production-пересчёта

1. При добавлении и перестановке уровней вся лестница пересчитывается по фактической истории игрока, а не по старому номеру уровня.
2. В сериях первый честно полученный уровень сохраняется; последующие ошибочно выданные уровни пересчитываются.
3. Ошибочно начисленные награды корректируются отдельными операциями без физического удаления финансовой истории и без ухода пользовательского баланса в минус.
4. Никакие production-изменения не выполняются до отдельного утверждения итоговой таблицы порогов, наград и плана коррекции.
