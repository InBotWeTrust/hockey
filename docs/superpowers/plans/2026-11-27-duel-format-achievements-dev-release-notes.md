# Что нового — dev, достижения форматов дуэлей

Текст для согласования перед выкладкой нового состава релиза:

1. В хоккейных заданиях появились цепочки побед и победных серий для всех форматов дуэлей.
2. Добавлены особые достижения «Снайпера», «Марафона» и «Ритма», новые иллюстрации и описания.

5. Задания на разницу шайб теперь учитывают только Экспресс, Микс и Классику.
